Recall for Omarchy v0.7.1 marks the agent skill it installs as its own.

- The `recall` skill's folder now holds a `.managed-by-recall` file, written when the skill is installed and when it's refreshed. Tools that sync a person's own skills between computers, Omacloud among them, read it and leave the folder to Recall on each one.
- The README has a sponsor link.
